# Changelog

All notable changes to Trip Countdown are listed here.
Versions follow [Semantic Versioning](https://semver.org/): **MAJOR.MINOR.PATCH**.

- **MAJOR**: big changes that work differently from before
- **MINOR**: new features
- **PATCH**: small fixes

## [1.2.0] - 2026-11-23
### Added
- Wide-screen dashboard layout: two columns on tablets, three columns on laptops and desktops
- Version number shown at the bottom of the page

### Changed
- Bigger title and countdown numbers on large screens
- Travel map is taller on large screens

## [1.1.0] - 2026-11-23
### Added
- Installable app: "Install" button, app icon, opens without the browser bar
- Works offline after the first open

## [1.0.0] - 2026-11-23
### Added
- Boarding-pass countdown with one-way and round-trip support
- Country, city and airport dropdowns for every country
- Time check comparing home and destination time zones
- Live weather and 16-day trip forecast (Open-Meteo)
- Airport-to-hotel travel time and arrival timeline (OpenStreetMap)
- Landing time in home or destination time, with an airport exit buffer
- Daily facts and encouraging lines for every country
- Destination flag colour themes
- Google My Maps travel map
- Full screen mode
- Trips saved locally in the browser
